## skell trust add

Trust a publisher's public key

```
skell trust add <publisher> <public-key-file | key> [flags]
```

### Examples

```
  skell trust add acme ./acme.pub
  skell trust add acme "skell-public-key AbC…=="
```

### Options

```
  -h, --help   help for add
```
