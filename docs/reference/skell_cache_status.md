## skell cache status

Show cache contents and sizes

### Synopsis

Prints a summary of each cached registry: alias, skill count, and last-fetched time.

```
skell cache status [flags]
```

### Examples

```
  skell cache status
```

### Options

```
  -h, --help   help for status
```
