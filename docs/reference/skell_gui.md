## skell gui

Launch the desktop GUI

### Synopsis

Launches the Skell desktop GUI when a GUI executable is installed
next to the skell CLI binary.

```
skell gui [flags]
```

### Examples

```
  skell gui
```

### Options

```
  -h, --help   help for gui
```
