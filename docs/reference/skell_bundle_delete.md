## skell bundle delete

Delete a bundle (its skills stay installed)

```
skell bundle delete <name> [flags]
```

### Options

```
  -h, --help          help for delete
      --repo string   Project (defaults to the current directory)
```

* [skell bundle](skell_bundle.md)	 - Named sets of skills (a role or team starter pack) you install in one step
