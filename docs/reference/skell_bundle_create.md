## skell bundle create

Create (or replace) a bundle

```
skell bundle create <name> <skill>... [flags]
```

### Examples

```
  skell bundle create frontend react css-review a11y-check --description "UI developer pack"
  skell bundle install frontend
```

### Options

```
      --description string   What the bundle is for
  -h, --help                 help for create
      --repo string          Project (defaults to the current directory)
```
