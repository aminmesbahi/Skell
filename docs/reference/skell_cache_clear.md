## skell cache clear

Delete all cached registry data

### Synopsis

Removes the entire local registry cache (~/.skell/cache). Registries will be re-cloned on next use.

```
skell cache clear [flags]
```

### Examples

```
  skell cache clear
```

### Options

```
  -h, --help   help for clear
```
